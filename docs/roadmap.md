# Roadmap

- Завершить каркас backend-сервиса.
- Добавить базовую CI-проверку сборки и типов.

- Описать OpenAPI contract для публичных read-only endpoint.
- Добавить health probes расширенного формата.
- Ввести integration tests для API.

## Phase 3

- Реализовать слой Figma read-only интеграции.
- Подготовить MCP transport и server boundaries.
- Добавить authn/authz и rate limiting по требованиям.
